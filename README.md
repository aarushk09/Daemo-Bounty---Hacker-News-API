# Daemo Calculator Agent

This is a simple Quickstart agent for Daemo that provides a calculator function.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set your API Key:
   ```powershell
   $env:DAEMO_AGENT_API_KEY="daemo_live_"
   ```

3. Run the agent:
   ```bash
   npm start
   ```
